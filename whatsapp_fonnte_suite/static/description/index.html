Tombol WhatsApp di Panel Chatter

Direct Binary Upload

Kirim Faktur & Dokumen PDF Otomatis

Mendukung pengiriman file PDF faktur, sales order, atau file gambar langsung dari attachment Odoo menggunakan metode multipart/form-data aman yang berfungsi pada localhost maupun server cloud.

Real-Time Device API

Scan QR Code & Monitor Device

Wizard interaktif untuk meminta dan memindai QR Code WhatsApp langsung dari Odoo. Dilengkapi pemantauan status koneksi, baterai smartphone, sisa kuota, dan masa aktif paket Fonnte secara akurat.

Dynamic Jinja-like

Template Pesan & Variabel Dinamis

Buat template pesan fleksibel untuk setiap model dokumen. Gunakan placeholder dinamis seperti {{self.name}} dan {{self.partner_id.name}} dengan riwayat pesan tercatat otomatis di Chatter.

Alur Kerja Cepat

Mulai Kirim Pesan dalam 4 Langkah Mudah

Konfigurasi mudah, siap digunakan dalam hitungan menit tanpa setup rumit.

01

Input API Token

Buka menu WhatsApp ➔ Konfigurasi Gateway, salin token API dari akun Fonnte Anda.

02

Scan QR Code

Klik tombol Hubungkan, pindai QR Code di layar menggunakan WhatsApp smartphone Anda.

03

Buka Dokumen

Buka Sales Order atau Faktur apa pun di Odoo, lalu klik tombol WhatsApp di Chatter.

04

Kirim Seketika

Pilih template, pastikan lampiran PDF aktif, lalu klik Kirim. Riwayat tersimpan rapi.

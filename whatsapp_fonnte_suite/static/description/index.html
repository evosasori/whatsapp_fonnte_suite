Odoo 18.0 Ready Community & Enterprise Fonnte WhatsApp Gateway

WhatsApp Fonnte Suite & Chatter

Integrasi WhatsApp Gateway untuk Odoo 18. Kirim notifikasi pesan dan lampiran dokumen PDF faktur secara instan langsung dari panel Chatter dokumen ERP Anda.

✨ Fitur & Keunggulan Utama

💬 Tombol WhatsApp di Panel Chatter

Tombol WhatsApp disematkan tepat di samping tombol Activities pada form Sales Order, Customer Invoice, Purchase Order, dan Stock Picking untuk memunculkan modal pengiriman pesan instan.

📎 Kirim Lampiran PDF & Gambar

Kirim file PDF faktur, penawaran harga, atau dokumen gambar langsung ke WhatsApp pelanggan via direct multipart binary upload yang bekerja di localhost maupun server cloud.

📱 Scan QR Code & Monitor Device

Wizard interaktif untuk scan QR Code langsung dari Odoo. Pantau status koneksi perangkat, baterai smartphone, sisa kuota, dan masa aktif paket Fonnte secara real-time.

⚡ Template Dinamis & Log Chatter

Dukung variabel dinamis Odoo seperti {{self.name}} dan {{self.partner_id.name}}. Seluruh pesan yang terkirim otomatis dicatat ke riwayat timeline Chatter.

🚀 Panduan Penggunaan Singkat

  1. Buka menu WhatsApp ➔ Konfigurasi Gateway, lalu masukkan API Token dari dashboard Fonnte.com.
  2. Klik tombol Hubungkan (Scan QR) untuk menautkan nomor WhatsApp Anda.
  3. Buka dokumen mana saja di Odoo (misal Sales Order atau Faktur Pelanggan), lalu klik tombol WhatsApp di samping tombol Activities pada panel Chatter.
  4. Pilih nomor penerima, tentukan template pesan dan lampiran PDF, lalu klik Kirim WhatsApp. Pesan akan terkirim dan tercatat di timeline dokumen.

📷 Tangkapan Layar Antarmuka

1. Konfigurasi Gateway & Status Perangkat Fonnte

Pengaturan token API, delay pengiriman pesan, serta monitoring kuota dan masa aktif paket Fonnte.

2. Uji Coba Pengiriman & Peringatan Paket Fonnte

Fitur uji coba kirim pesan dan deteksi otomatis kapabilitas paket Free / Super / Ultra untuk pengiriman lampiran media.

3. Integrasi Tombol WhatsApp di Panel Chatter Odoo 18

Tombol WhatsApp terletak di panel Chatter dokumen transaksi (Quotation / Sales Order) dengan pencatatan log pesan terkirim.

4. Modal Pop-up Kirim Pesan & Lampiran PDF

Modal wizard pengiriman pesan interaktif: deteksi otomatis nomor kontak pelanggan, pemilihan template, dan lampiran PDF faktur.

⚠️ Sanggahan & Kebijakan Anti-Spam (Unofficial WhatsApp API)

Modul ini menggunakan layanan gateway pihak ketiga tidak resmi (Unofficial API via Fonnte.com) dan tidak terafiliasi dengan Meta Inc. Pengembang modul TIDAK BERTANGGUNG JAWAB atas segala bentuk pembatasan, pemblokiran nomor (banned / suspend), atau laporan spam yang ditimbulkan akibat penggunaan nomor Anda.
